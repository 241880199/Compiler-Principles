## Global Constraints

- **语言标准**：`-std=c99`，编译必须**零 gcc 警告**（`-Wall` 已开）
- **不要用 `make -j`**：仓库 Makefile 里 `syntax.tab.c syntax.tab.h:` 是多目标规则，`-j` 下会并发跑两次 bison（Makefile 注释里有完整说明）
- **不要在正常流程写 stderr**：实验一/二的输出契约是 stdout；stderr 只留给内部错误（`abort` 前的提示）
- **交付包 `Code/` 下不得建子目录**，源码一律平铺
- **交付包必须含 `Code/lexer.c`**：现场由 flex 从 `lexical.l` 生成，**不得存副本**（副本会静默过期）
- **判分机用自己的参考 Makefile**（`作业一/Makefile_ref`），其 `parser` 规则 `$(filter-out $(LFO),$(OBJS))` 会把 `lex.yy.o` 滤出链接行
- **「零警告」的判据必须用 `bash scripts/check_warnings.sh <build.log>`**，**不要**裸用
  `grep -c warning`：bison 在任何正确构建上都会打 `src/syntax.y: warning: 3 shift/reduce conflicts`，
  裸计数**恒为 1**，是一条永远亮的假红灯（实验一/二的交付记录里都栽过这个）。
  脚本只数 gcc 形态的 `文件:行:列: warning:`。冲突数另有 `run_tests.sh` 的哨兵把关（恰好 3）。
- **Python 侧一律只用标准库，不得引入第三方依赖**（pytest 等在本机三个解释器里都没有装）。
  测试用 `scripts/rtest.py` 跑：`python -I scripts/rtest.py <目录> …`。
  理由：自检依赖需要先安装的东西，等于给跑得起来加门槛 —— 本项目最怕的那类失效。
- **`make symtab-test` 在 `main` 上是预先损坏的**（`Test/unit/test_symtab.c` 断言了实验二已删除的
  `symGlobalList()`）。这是 `lab3` 继承来的缺陷，由 Task 1 之后的一笔「inherit fix」修掉；
  在那之前不要把 `symtab-test` 计入任何验收判据。
- **报告 ≤3 页**，最小字号五号（英文 11 号），必须含姓名/学号/联系邮箱
- **命名风格**：变量 `v1, v2…`、临时变量 `t1, t2…`、标号 `label1, label2…`（要求书明说非强制）
- **隔离**：不得改动实验二的语义检查逻辑（`semantic.c` 只允许新增"遇到结构体 → 记标志并返回"的最小改动）
- **构建与测试在 WSL 内执行**：`wsl.exe -d Ubuntu-22.04`（默认发行版是 `docker-desktop`，里面没有 bash/xelatex）
- **WSL 命令转义**：经多层引号传 `$?` 会被错误展开；脚本里的断言一律写在 WSL **内部的脚本文件**里，不要塞进一行的 `bash -c`

- [ ] **Step 0: 先落一个不依赖第三方的最小测试运行器**

**为什么**：本机三个解释器（Windows 3.11 / 3.14、WSL 3.10）**都没有装 pytest**

新建 `scripts/rtest.py`（只用标准库）：

```python
"""极简测试运行器：收集 test_*.py 里所有 test_* 可调用对象并逐个运行。

为什么不用 pytest：本机三个解释器都没装它，而让自检依赖一个需要先安装的东西，
等于给跑得起来加了一道门槛。本运行器零依赖、可直接在交付环境里跑。

用法： python -I scripts/rtest.py <目录> [<目录> ...]
退出码：全部通过 0；有失败 1；**一个用例都没跑到也判 1**（防止语料被清空后假绿）。
"""
import importlib.util, os, sys, traceback


def _load(path):
    name = os.path.splitext(os.path.basename(path))[0]
    spec = importlib.util.spec_from_file_location(name, path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def main(dirs):
    files = []
    for d in dirs:
        for n in sorted(os.listdir(d)):
            if n.startswith("test_") and n.endswith(".py"):
                files.append(os.path.join(d, n))
    passed = failed = 0
    for f in files:
        try:
            mod = _load(f)
        except Exception:
            failed += 1
            print("FAIL %s (导入期异常)" % f)
            traceback.print_exc()
            continue
        for attr in sorted(dir(mod)):
            if attr.startswith("test_") and callable(getattr(mod, attr)):
                try:
                    getattr(mod, attr)()
                    passed += 1
                except Exception:
                    failed += 1
                    print("FAIL %s::%s" % (f, attr))
                    traceback.print_exc()
    print("pass=%d fail=%d" % (passed, failed))
    if passed == 0:
        print("没有任何用例跑到 —— 判为红")
        return 1
    return 1 if failed else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

**自证判别力**：在一个临时目录里放一个 `test_x.py`，其中 `test_boom` 故意
`raise AssertionError("x")`，跑一次必须看到 `pass=0 fail=1` 且退出码 1；
把那个函数改成就地返回，必须 `pass=1 fail=0` 且退出码 0。两步实测输出记进报告。

- [ ] **Step 1: 写失败的测试**（`Test/lab3/unit_parse/t1.ir`）

```

DEC a 8
t1 := #5
t2 := &a + #4
*t2 := t1
```

> ⚠️ **末两行不是凑数**：`x := CALL f` 与 `GOTO label2` 分别引用了 `f` 与 `label2`，
> 而它们**必须有定义**（`load_ir` 末尾的标号存在性检查会拒绝无定义的引用）。
> **追加在末尾**是为了让上面断言的 0–9 号下标**一个都不动**。

`Test/lab3/unit_parse/test_parse.py`：

```python
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "..", "..", "scripts"))
from irsim_ref import load_ir, IRSyntaxError, UndefinedLabelError

HERE = os.path.dirname(os.path.abspath(__file__))


def _ir(name):
    return load_ir(os.path.join(HERE, name))


def _must_reject(name):
    """断言夹具被拒；返回捕获到的 IRSyntaxError（便于再断言其内容）。"""
    try:
        _ir(name)
    except IRSyntaxError as e:
        return e
    raise AssertionError("%s 应当被拒绝，但 load_ir 接受了它" % name)


def _must_leak_valueerror(name):
    """夹具在装载期抛**裸 ValueError** 而不是 IRSyntaxError（契约见模块 docstring）。"""
    try:
        _ir(name)
    except IRSyntaxError as e:
        raise AssertionError(
            "%s 应当漏出 ValueError（真机契约），却抛了 IRSyntaxError: %r" % (name, e))
    except ValueError:
        return
    raise AssertionError("%s 应当抛 ValueError，但没有抛任何异常" % name)


# ---------------------------------------------------------------- 基本形状

def test_parses_all_forms():
    p = load_ir(os.path.join(HERE, "t1.ir"))
    assert p.entry == 0
    assert p.labels["label1"] == 8   # LABEL label1 : 是第 9 行 ⇒ 下标 8（同用例已断言 codes[8]）
    assert p.codes[0] == ("LABEL", "main")
    assert p.codes[1] == ("DEC",)
    assert p.codes[2] == ("MOV", "t1", "#5")
    assert p.codes[3] == ("ARITH", "t2", "&a", "+", "#4")
    assert p.codes[4] == ("MOV", "*t2", "t1")
    assert p.codes[5] == ("CALL", "x", "f")
    assert p.codes[6] == ("IF", "x", ">", "#0", "label1")
    assert p.codes[7] == ("GOTO", "label2")
    assert p.codes[8] == ("LABEL", "label1")
    assert p.codes[9] == ("RETURN", "#0")

def test_funcs_records_variables():
    """`funcs` 是 Task 3 执行引擎消费的接口（CALL 时靠它重分配地址）⇒ 必须被钉住。

    顺序 = 函数体内**变量首次出现**的顺序；`#5`/`&a` 这类操作数不登记（`&a` 里的 `a`
    早已登记，`#5` 是立即数）。`f` 体为空 ⇒ 空列表。
    """
    p = load_ir(os.path.join(HERE, "t1.ir"))
    assert p.funcs == {"main": ["a", "t1", "t2", "x"], "f": []}

def test_div_becomes_floordiv():
    p = load_ir(os.path.join(HERE, "t2.ir"))   # 内容：FUNCTION main : / t := a / b
    assert p.codes[1] == ("ARITH", "t", "a", "//", "b")

def test_rejects_single_token_line():
    """`a:=b` 分词后只有 **1 个** token ⇒ 走的是 sanity_check 末尾的兜底 else。

    ⚠️ 它**不**覆盖 `strs[1] == ":="` 那个分支 —— 把整个 `:=` 分支删掉这个用例照样通过。
    真正走 `:=` 分支并在其中失败的用例见 test_rejects_arith_with_bad_operator /
    test_rejects_hash_on_assignment_lhs / test_rejects_call_with_extra_operand。
    """
    _must_reject("t3.ir")   # 内容：FUNCTION main : / a:=b

def test_blank_lines_are_skipped_without_index():
    p = load_ir(os.path.join(HERE, "t4.ir"))   # 第 2 行是空行
    assert p.codes[1] == ("GOTO", "label1")

def test_rejects_undefined_label():
    """钉住 label_check 这层**我们自己加的**防御性检查（非反解语义，见其 docstring）。

    """
    try:
```

```python
"""irsim 的无头参考实现。

语义逐条来自对 作业三/irsim.pyc（版本 2.0.2，编译于 2023-02-02）的字节码反解，
与该设计文档 §3 一一对应。本文件**不依赖 PyQt、不依赖 Python 3.8**。

**异常契约（调用方必读）**：语法错误抛 `IRSyntaxError`；但**操作数里的整数解析失败
会原样漏出 `ValueError`**（例：`DEC a abc`、`#abc`）。
这不是疏漏，而是**忠实**：真机 `sanity_check` 捕的正是 `(IRSyntaxError, ValueError)`。
⇒ 调用方若只 `except IRSyntaxError` 会漏掉这一类；**不要"顺手修"成 `IRSyntaxError`**，
测试 `test_int_parse_failure_leaks_valueerror` 专门钉住这条行为。
"""

import sys

RELOPS = (">", "<", ">=", "<=", "==", "!=")
ARITHOPS = ("+", "-", "*", "/")


class IRSyntaxError(Exception):
    pass


class DuplicatedLabelError(Exception):
    pass


class DuplicatedVariableError(Exception):
    pass


class UndefinedLabelError(Exception):
    pass


class Program:
    def __init__(self):
        self.codes = []          # list[tuple]
        self.labels = {}         # name -> 在当前 codes 中的下标（LABEL 与 FUNCTION 都登记）
        self.funcs = {}          # 函数名 -> 函数体变量名列表（按出现顺序）
        self.entry = -1
        self.symtab = {}         # 名 -> [地址, 大小, 是否数组]
        self.offset = 0
        self.current_function = None


def load_ir(path):
    """解析 .ir 文件。与真实 loadFile 一致：逐行、空白行整行跳过、每行一条指令。"""
    p = Program()
    with open(path, "r") as fp:
        for raw in fp:
            if raw.isspace():
                continue
            sanity_check(p, raw, len(p.codes))
    if p.entry == -1:
        raise IRSyntaxError("Cannot find program entrance (no FUNCTION main : line)")
    label_check(p)
    if p.offset > 1048576:
        raise IRSyntaxError("offset exceeds 1MiB")
    return p


def _table_insert(p, var, size=4, is_array=False):
    if var.isdigit():
        raise IRSyntaxError("bare number used as operand: %r" % var)
    if var[0] in "&*":
        var = var[1:]
    elif var[0] == "#":
        int(var[1:])            # 与真实实现一致：非数字会抛 ValueError
        return
    if var in p.symtab:
        return
    if p.current_function is None:
        raise IRSyntaxError("line does not belong to any function")
    p.funcs.setdefault(p.current_function, []).append(var)
    if p.current_function == "main":
        p.symtab[var] = [p.offset, size, is_array]
        p.offset += size
    else:
        p.symtab[var] = [-1, size, is_array]


def sanity_check(p, line, lineno):
    strs = line.split()
    if strs[0] in ("LABEL", "FUNCTION"):
        if len(strs) != 3 or strs[2] != ":":
            raise IRSyntaxError("bad label line: %r" % line)
        if strs[1] in p.labels:
            raise DuplicatedLabelError(strs[1])
        p.labels[strs[1]] = lineno
        if strs[1] == "main":
            if strs[0] == "LABEL":
                raise IRSyntaxError("LABEL main is not allowed")
            p.entry = lineno
        if strs[0] == "FUNCTION":
            p.current_function = strs[1]
            p.funcs[strs[1]] = []
        p.codes.append(("LABEL", strs[1]))
        return

    if p.current_function is None:
        raise IRSyntaxError("line %d does not belong to any function" % lineno)

    if strs[0] == "GOTO":
        if len(strs) != 2:
            raise IRSyntaxError(line)
        p.codes.append(("GOTO", strs[1]))
    elif strs[0] in ("RETURN", "READ", "WRITE", "ARG", "PARAM"):
        if len(strs) != 2:
            raise IRSyntaxError(line)
        if strs[0] in ("READ", "PARAM") and not strs[1][0].isalpha():
            raise IRSyntaxError(line)
        _table_insert(p, strs[1])
        p.codes.append((strs[0], strs[1]))
    elif strs[0] == "DEC":
        if len(strs) != 3 or int(strs[2]) % 4 != 0:
            raise IRSyntaxError(line)
        if strs[1] in p.symtab:
            raise DuplicatedVariableError(strs[1])
        _table_insert(p, strs[1], int(strs[2]), True)
        p.codes.append(("DEC",))
    elif strs[0] == "IF":
        if len(strs) != 6 or strs[4] != "GOTO" or strs[2] not in RELOPS:
            raise IRSyntaxError(line)
        _table_insert(p, strs[1])
        _table_insert(p, strs[3])
        p.codes.append(("IF", strs[1], strs[2], strs[3], strs[5]))
    elif len(strs) >= 3 and strs[1] == ":=":
        if strs[0][0] in "&#":
            raise IRSyntaxError(line)
        _table_insert(p, strs[0])
        if strs[2] == "CALL":
            if len(strs) != 4:
                raise IRSyntaxError(line)
            p.codes.append(("CALL", strs[0], strs[3]))
        elif len(strs) == 3:
            _table_insert(p, strs[2])
            p.codes.append(("MOV", strs[0], strs[2]))
        elif len(strs) == 5 and strs[3] in ARITHOPS:
            _table_insert(p, strs[2])
            _table_insert(p, strs[4])
            op = "//" if strs[3] == "/" else strs[3]
            p.codes.append(("ARITH", strs[0], strs[2], op, strs[4]))
        else:
            raise IRSyntaxError(line)
    else:
        raise IRSyntaxError(line)


def label_check(p):
    """所有被引用的标号都必须有定义。

    ⚠️ **保真度声明：本函数不是从 irsim.pyc 反解出来的。** 真机确有 `labelCheck` 与
    `UndefinedLabelError`，但它的实现**未被反解确证**（其 code 对象的常量表里没有
    `'GOTO'`/`'IF'`/`'CALL'` 这类关键字，与下面按关键字比较的写法形状不同）。
    这里保留的是一层**我们自己的防御性检查**，目的是保证生成的 IR 自洽。
    对本实验**无实害**：我们生成的 IR 里每个被引用的标号都有定义，故本检查永不触发。
    真机行为若与此不同，也不会影响任何判据。
    """
    for c in p.codes:
        if c[0] == "GOTO" and c[1] not in p.labels:
            raise UndefinedLabelError(c[1])
        if c[0] == "IF" and c[4] not in p.labels:
            raise UndefinedLabelError(c[4])
        if c[0] == "CALL" and c[2] not in p.labels:
            raise UndefinedLabelError(c[2])
```

```python
class Result:
    def __init__(self):
        self.outputs = []
        self.instr_cnt = 0
        self.status = "ok"       # 'ok' | 'memory' | 'pc'


MEM_WORDS = 262144


def run(path, inputs=(), trace=False):
    p = load_ir(path)
    st = _State(p, list(inputs))
    _execute(st, trace)
    st.result.instr_cnt = st.instr_cnt
    return st.result


class _State:
    def __init__(self, p, inputs):
        self.p = p
        self.inputs = inputs
        self.mem = [0] * MEM_WORDS
        self.symtab = {k: list(v) for k, v in p.symtab.items()}
        self.call_stack = []          # (ip, funcname, old_addrs, old_offset)
        self.arg_stack = []
        self.offset = p.offset
        self.instr_cnt = 0
        self.result = Result()

    # ---- 取值（spec §3.3） ----
    def get_value(self, var):
        if var[0] == "#":
            return int(var[1:])
        if var[0] == "&":
            return self.symtab[var[1:]][0]
        if var[0] == "*":
            return self.mem[self.mem[self.symtab[var[1:]][0] // 4] // 4]
        return self.mem[self.symtab[var][0] // 4]

    def store_var(self, var, value):
        if var[0] == "*":
            self.mem[self.mem[self.symtab[var[1:]][0] // 4] // 4] = value
        else:
            self.mem[self.symtab[var][0] // 4] = value

    def new_addr(self, size):
        a = self.offset
        self.offset += size
        return a


def _execute(st, trace):
    p = st.p
    ip = p.entry
    while ip >= 0:
        if ip >= len(p.codes):
            st.result.status = "pc"
            return
        code = p.codes[ip]
        st.instr_cnt += 1
        if trace:
            print("%4d  %-40s  ip=%d" % (st.instr_cnt, code, ip), file=sys.stderr)
        try:
            nxt = _step(st, code, ip)
        except IndexError:
            st.result.status = "memory"
            return
        if nxt is None:          # RETURN 且调用栈为空 => 正常结束
            return
        ip = nxt


def _step(st, code, ip):
    p = st.p
    op = code[0]

    if op == "LABEL":
        return ip + 1
    if op == "READ":
        # 真机 `result, ok = QInputDialog.getInt(...)`：**ok 为假（取消）时什么都不写**。
        # 输入序列耗尽 = 取消 ⇒ 不写，变量保留旧值（§3.3）。
        if st.inputs:
            st.store_var(code[1], st.inputs.pop(0))
        return ip + 1
    if op == "WRITE":
        st.result.outputs.append(st.get_value(code[1]))
        return ip + 1
    if op == "GOTO":
        # ★★ 计数口径（§3.6）：真机 execute_code 写 labelTable[x]（= LABEL 行自身下标），
        # 主循环再**无条件** +1 ⇒ 跳转命中的 LABEL 行被跨过（不执行、不计数）。
        return p.labels[code[1]] + 1
    if op == "IF":
        x, relop, y, z = code[1], code[2], code[3], code[4]
        v1, v2 = st.get_value(x), st.get_value(y)
        if _eval_relop(v1, relop, v2):
            return p.labels[z] + 1        # ★ 同 GOTO：跳转命中标号不计
        return ip + 1
    if op == "MOV":
        st.store_var(code[1], st.get_value(code[2]))
        return ip + 1
    if op == "ARITH":
        v1, v2 = st.get_value(code[2]), st.get_value(code[4])
        # ★ 目标**不走 `store_var`**：真机此处就是 `mem[symTable[code[1]][0] // 4] = ...`，
        #   不做 `*` 解引用（`tableInsert` 已把 `*` 剥掉，表里只有 `x`）。
        #   ⇒ `*x := a op b` 在此抛 **KeyError**；真机不捕它，我们也不捕（§3.7-2）。
        #   注意顺序与真机同构：Python 先算 RHS 再解析赋值目标。
        st.mem[st.symtab[code[1]][0] // 4] = _eval_arith(v1, code[3], v2)
        return ip + 1
    if op == "DEC":
        return ip + 1
    if op == "ARG":
        st.arg_stack.append(st.get_value(code[1]))
        return ip + 1
    if op == "PARAM":
        st.store_var(code[1], st.arg_stack.pop())
        return ip + 1
    if op == "CALL":
        dst, fname = code[1], code[2]
        old_addrs = {}
        old_offset = st.offset
        for k in p.funcs.get(fname, []):
            old_addrs[k] = list(st.symtab[k])
            st.symtab[k] = [st.new_addr(st.symtab[k][1]), st.symtab[k][1], st.symtab[k][2]]
        st.call_stack.append((ip + 1, dst, old_addrs, old_offset))
        return p.labels[fname] + 1        # ★ 同 GOTO：跳转命中 FUNCTION 行不计
    if op == "RETURN":
        # `ret_ip` 已是调用点的下一条（CALL 压栈的就是 `ip + 1`）⇒ 不再 +1。
        if not st.call_stack:
            return None
        rv = st.get_value(code[1])
        ret_ip, dst, old_addrs, old_offset = st.call_stack.pop()
        for k, v in old_addrs.items():
            st.symtab[k] = v
        st.offset = old_offset
        # ★ 与上面的 `ARITH` **同构**：真机此处就是
        #   `mem[symTable[stackItem[1]][0] // 4] = returnValue` —— 同样是**裸下标**，
        #   不做 `*` 解引用（`tableInsert` 已把 `*` 剥掉，表里只有 `p`、没有 `*p`）。
        #   ⇒ `*p := CALL f` 在此抛 **KeyError**；真机不捕它，我们也不捕（§3.7-2）。
        #   注意这与 `MOV` **不同**（`MOV` 走 `store_var`、支持 `*` 目标）——见 deref_mov.ir。
        st.mem[st.symtab[dst][0] // 4] = rv
        return ret_ip
    raise IRSyntaxError("unhandled %r" % (code,))


def _eval_relop(a, relop, b):
    if relop == ">":  return a > b
    if relop == "<":  return a < b
    if relop == ">=": return a >= b
    if relop == "<=": return a <= b
    if relop == "==": return a == b
    if relop == "!=": return a != b
    raise IRSyntaxError(relop)


def _eval_arith(a, op, b):
    # 与真实实现一致：装载期已把 '/' 改写为 '//'，故这里 Integer 除法向下取整
    if op == "+":  return a + b
    if op == "-":  return a - b
    if op == "*":  return a * b
    if op == "//": return a // b
    raise IRSyntaxError(op)
```

```c
    FILE *f = fopen(getenv("CMM_IN"), "r");
    if (!f) return;
    while (fscanf(f, "%d,", &__in[__nin]) == 1) __nin++;
    fclose(f);
}
static int __read(void) { __load(); return __ip < __nin ? __in[__ip++] : 0; }
/* 与虚拟机一致：'/' 被改写为向下取整（spec §3.7-1、P1） */
static int __div(int a, int b) { return (a / b) - ((a % b != 0) && ((a < 0) != (b < 0))); }
```

```c
#define IR_H

typedef struct Operand_ *Operand;
struct Operand_ {
    /* OP_ADDR 表示「取地址」形式 `&x`：既是 `ARG &arr` 的操作数，也是
       `x := &y + #8` 这类 ARITH 的操作数（虚拟机 getValue 认识 `&` 前缀）。
       `*x` 不单设 kind：它只出现在赋值两侧，由 IR_ASSIGN_DEREF / IR_DEREF_ASSIGN 表达。 */
    enum { OP_VAR, OP_CONST, OP_LABEL, OP_FUNC, OP_ADDR } kind;
    const char *name;      /* OP_VAR / OP_LABEL / OP_FUNC / OP_ADDR */
    int         value;     /* OP_CONST */
};

typedef struct InterCode {
    enum { IR_LABEL, IR_FUNCTION, IR_ASSIGN, IR_ADD, IR_SUB, IR_MUL, IR_DIV,
           IR_ADDR, IR_DEREF_ASSIGN, IR_ASSIGN_DEREF, IR_GOTO, IR_IF, IR_RETURN,
           IR_DEC, IR_ARG, IR_CALL, IR_PARAM, IR_READ, IR_WRITE } kind;
    union {
        struct { Operand x; } one;                     /* GOTO/RETURN/ARG/PARAM/READ/WRITE/LABEL/FUNCTION */
        struct { Operand x, y; } assign;               /* x := y / x := &y / x := *y */
        struct { Operand x, y, z; } binop;             /* x := y op z */
        struct { Operand x, y; } deref;                /* *x := y （IR_DEREF_ASSIGN） */
        struct { Operand x, y, z; int relop; } iff;    /* IF x relop y GOTO z */
        struct { Operand x; int size; } dec;           /* DEC x size */
        struct { Operand x, f; } call;                 /* x := CALL f */
    } u;
} InterCode;

typedef struct InterCodeList {
    InterCode *code;
    struct InterCodeList *prev, *next;
} InterCodeList;

Operand opVar(const char *name);
Operand opConst(int v);
Operand opLabel(const char *name);
Operand opFunc(const char *name);      /* ★ 传源码里的真实函数名 */
Operand opAddr(const char *name);
```

- [ ] **Step 4: 实现 `src/ir.c`**

要点（完整实现照此写）：

- 用**带哨兵的双向循环链表**：`irList()` 造一个哨兵 `head`，`head->next = head->prev = head`。
  这样"表空"与"表头/表尾插入"无需特判，`deleteCode` 也不必判空。
- `irAppend(tail, c)`：在 `tail` 之后插入，返回新结点（新尾）。
- `printIR` 从 `head->next` 遍历到 `head`，每个 `InterCode` 打一行，**行尾恰好一个 `\n`，不产生空行**（spec §3.7-4）。
- 文本格式：

```c
static void printOperand(FILE *out, Operand o) {
    switch (o->kind) {
    case OP_VAR:   fputs(o->name, out); break;
    case OP_CONST: fprintf(out, "#%d", o->value); break;
    case OP_LABEL: fputs(o->name, out); break;
    case OP_FUNC:  fputs(o->name, out); break;      /* 真实函数名，虚拟机靠它查 labelTable */
    case OP_ADDR:  fprintf(out, "&%s", o->name); break;
    }
}

void printIR(FILE *out, InterCodeList *any) {
    InterCodeList *h = irHead(any), *p;
    for (p = h->next; p != h; p = p->next) {
        InterCode *c = p->code;
        switch (c->kind) {
        case IR_LABEL:    fprintf(out, "LABEL "); printOperand(out, c->u.one.x); fprintf(out, " :\n"); break;
        case IR_FUNCTION: fprintf(out, "FUNCTION "); printOperand(out, c->u.one.x); fprintf(out, " :\n"); break;
        case IR_ASSIGN:
            printOperand(out, c->u.assign.x); fprintf(out, " := ");
            printOperand(out, c->u.assign.y); fprintf(out, "\n"); break;
        case IR_ADDR:
            printOperand(out, c->u.assign.x); fprintf(out, " := &");
            printOperand(out, c->u.assign.y); fprintf(out, "\n"); break;
        case IR_ASSIGN_DEREF:
            printOperand(out, c->u.deref.x); fprintf(out, " := *");
            printOperand(out, c->u.deref.y); fprintf(out, "\n"); break;
        case IR_DEREF_ASSIGN:
            fprintf(out, "*"); printOperand(out, c->u.deref.x); fprintf(out, " := ");
            printOperand(out, c->u.deref.y); fprintf(out, "\n"); break;
        case IR_ADD: case IR_SUB: case IR_MUL: case IR_DIV: {
            static const char *nm[4] = { "+", "-", "*", "/" };
            printOperand(out, c->u.binop.x); fprintf(out, " := ");
            printOperand(out, c->u.binop.y); fprintf(out, " %s ", nm[c->kind - IR_ADD]);
            printOperand(out, c->u.binop.z); fprintf(out, "\n"); break;
        }
        case IR_GOTO:   fprintf(out, "GOTO "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        case IR_IF:
            fprintf(out, "IF "); printOperand(out, c->u.iff.x);
            fprintf(out, " %s ", irRelopText(c->u.iff.relop));
            printOperand(out, c->u.iff.y); fprintf(out, " GOTO ");
            printOperand(out, c->u.iff.z); fprintf(out, "\n"); break;
        case IR_RETURN: fprintf(out, "RETURN "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        case IR_DEC:    fprintf(out, "DEC "); printOperand(out, c->u.dec.x);
                        fprintf(out, " %d\n", c->u.dec.size); break;
        case IR_ARG:    fprintf(out, "ARG "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        case IR_CALL:   printOperand(out, c->u.call.x); fprintf(out, " := CALL ");
                        printOperand(out, c->u.call.f); fprintf(out, "\n"); break;
        case IR_PARAM:  fprintf(out, "PARAM "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        case IR_READ:   fprintf(out, "READ "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        case IR_WRITE:  fprintf(out, "WRITE "); printOperand(out, c->u.one.x); fprintf(out, "\n"); break;
        }
    }
}
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "translate.h"
#include "ir.h"
#include "symtab.h"
#include "type.h"
#include "util.h"

static int isTok(Node *n, const char *name) {
    return n && n->kind == NODE_TOKEN && strcmp(n->name, name) == 0;
}

ExpKind classifyExp(Node *e) {
    if (e->nchild == 1) {
        if (isTok(e->child[0], "INT"))   return EX_INT;
        if (isTok(e->child[0], "ID"))    return EX_ID;
        /* `Exp : FLOAT` 与 `Exp : INT` **形状完全相同**（nchild==1、child[0] 是终结符），
         * 只有 token 名字能区分。假设 1 保证实验三输入不含浮点，故正常判分路径上这条
         * 不可达；但**不可达不等于可以静默** —— 若兜底 `return EX_INT`，一个浮点字面量
         * 会被当成整数，下游拿它的 lexeme（"1.5"）当整数用，生成一份"看着挺像那么回事"
         * 的错 IR，端到端测不出来。故与全表其它未识别分支一致：**响亮失败**。 */
        goto bad;
    }
    if (e->nchild == 2) return EX_UNARY;
    if (e->nchild == 3) {
        if (isTok(e->child[0], "LP")) return EX_PAREN;
        if (isTok(e->child[0], "ID") && isTok(e->child[1], "LP")) return EX_CALL0;
        if (isTok(e->child[1], "DOT")) return EX_FIELD;
        return EX_BINOP;
    }
    if (e->nchild == 4) {
        if (isTok(e->child[0], "ID")) return EX_CALLN;
        if (isTok(e->child[1], "LB")) return EX_INDEX;
    }
bad:
    /* 诊断带 nchild、行号与孩子 token 名：看日志的人一眼知道是 FLOAT 还是别的形状。 */
    fprintf(stderr, "internal error: unclassified Exp (nchild=%d) at line %d, child[0]=%s\n",
            e->nchild, nodeLine(e),
            (e->nchild >= 1 && e->child[0] && e->child[0]->name) ? e->child[0]->name : "(none)");
    abort();
}

StmtKind classifyStmt(Node *s) {
    if (s->nchild == 1) {
        /* 同族分支都先判 NULL 再判类型（见下 nchild==2 处）：失败形态统一是 abort，不是段错误。 */
        if (s->child[0] == NULL || s->child[0]->type != NT_COMPST) goto bad;
        return ST_COMPST;
    }
    if (s->nchild == 2) {
        if (s->child[0] == NULL || s->child[0]->kind != NODE_GRAMMAR) goto bad;  /* error SEMI */
        return ST_EXP;
    }
    if (s->nchild == 3) {
        if (isTok(s->child[0], "RETURN")) return ST_RETURN;
        goto bad;
    }
    if (s->nchild == 5) {
        if (isTok(s->child[0], "IF"))    return ST_IF;
        if (isTok(s->child[0], "WHILE")) return ST_WHILE;
        goto bad;
    }
    if (s->nchild == 7) return ST_IFELSE;
bad:
    fprintf(stderr, "internal error: unclassified Stmt (nchild=%d) at line %d\n",
            s->nchild, nodeLine(s));
    abort();
}
```

```c
InterCodeList *translateExp(InterCodeList *tail, Node *e, Operand place, int *placeIsAddr) {
    if (placeIsAddr) *placeIsAddr = 0;
    switch (classifyExp(e)) {
    case EX_INT:
        if (place) { InterCode *c = newCode(IR_ASSIGN);
                     c->u.assign.x = place;
                     c->u.assign.y = opConst(atoi(e->child[0]->lexeme));
                     tail = irAppend(tail, c); }
        return tail;

    case EX_ID:
        if (place) { InterCode *c = newCode(IR_ASSIGN);
                     c->u.assign.x = place;
                     c->u.assign.y = opVar(varNameOf(e->child[0]->lexeme));
                     tail = irAppend(tail, c); }
        return tail;

    case EX_BINOP: {
        const char *op = e->child[1]->name;
        if (strcmp(op, "ASSIGNOP") == 0) return translateAssign(tail, e, place);
        tail = translateBinArith(tail, e, place, op);
        return tail;
    }

    case EX_UNARY:
        if (isTok(e->child[0], "NOT")) return translateNotAsValue(tail, e, place);
        /* 取负 */
        if (place) {
            Operand t1 = opVar(newTempName());
            tail = translateExp(tail, e->child[1], t1, NULL);
            InterCode *c = newCode(IR_SUB);
            c->u.binop.x = place; c->u.binop.y = opConst(0); c->u.binop.z = t1;
            tail = irAppend(tail, c);
        } else {
            tail = translateExp(tail, e->child[1], NULL, NULL);
        }
        return tail;

    case EX_PAREN:
        return translateExp(tail, e->child[1], place, placeIsAddr);

    case EX_CALL0:
        return translateCall0(tail, e, place);          /* Task 10 */

    case EX_CALLN:
        return translateCallN(tail, e, place);          /* Task 10 */

    case EX_INDEX:
        return translateIndex(tail, e, place, placeIsAddr);   /* Task 11 */

    case EX_FIELD:
        return translateField(tail, e, place);          /* 选做 3.1，本实验不实现 */
    }
    return tail;
}
```

```c
static InterCodeList *translateBinArith(InterCodeList *tail, Node *e, Operand place, const char *op) {
    int kind = 0;
    if      (strcmp(op, "PLUS")  == 0) kind = IR_ADD;
    else if (strcmp(op, "MINUS") == 0) kind = IR_SUB;
    else if (strcmp(op, "STAR")  == 0) kind = IR_MUL;
    else if (strcmp(op, "DIV")   == 0) kind = IR_DIV;
    else {
        /* RELOP / AND / OR 走条件翻译，见 Task 9 */
        return translateCondAsValue(tail, e, place);
    }
    if (!place) {
        /* 值不被需要也要求值：两侧可能有副作用（函数调用），必须照常翻译 */
        Operand t1 = opVar(newTempName()), t2 = opVar(newTempName());
        tail = translateExp(tail, e->child[0], t1, NULL);
        tail = translateExp(tail, e->child[2], t2, NULL);
        return tail;
    }
    Operand t1 = opVar(newTempName()), t2 = opVar(newTempName());
    tail = translateExp(tail, e->child[0], t1, NULL);
    tail = translateExp(tail, e->child[2], t2, NULL);
    InterCode *c = newCode(kind);
    c->u.binop.x = place; c->u.binop.y = t1; c->u.binop.z = t2;
    return irAppend(tail, c);
}
```

赋值（**本设计的核心**）：

```c
static InterCodeList *translateAssign(InterCodeList *tail, Node *e, Operand place) {
    Node *lhs = e->child[0];
    if (classifyExp(lhs) != EX_ID) {
        /* 数组元素左值由 Task 11 处理；结构体域不实现 */
        return translateAssignToLValue(tail, e, place);
    }
    Operand dst = opVar(varNameOf(lhs->child[0]->lexeme));
    tail = translateExp(tail, e->child[2], dst, NULL);   /* ★ 直接算进目标变量 */
    if (place) {                                          /* 赋值表达式的值还要用 */
        InterCode *c = newCode(IR_ASSIGN);
        c->u.assign.x = place; c->u.assign.y = dst;
        tail = irAppend(tail, c);
    }
    return tail;
}
```

> ★ **这是"`place` 作为继承属性"的落点**：`x = <expr>;` 时不产生 `t := <expr>; x := t`
> 两条，而是把 `x` 直接当 `place` 传给子表达式，只产生一条。
> 要求书 4.1.6 样例 1 自己给出的"优化后版本"正是这个形态。

```c
    snprintf(buf, sizeof buf, "t%d", ++tmpSeq);

    snprintf(buf, sizeof buf, "label%d", ++labelSeq);

      varMap[varMapN].src = xstrdup(src); varMap[varMapN].ir = xstrdup(buf); varMapN++; }
    return varMap[varMapN - 1].ir;
}
void translateResetNames(void) { tmpSeq = labelSeq = varSeq = varMapN = 0; }
```

```c
InterCodeList *translateCond(InterCodeList *tail, Node *e, const char *lt, const char *lf) {
    ExpKind k = classifyExp(e);

    if (k == EX_BINOP && strcmp(e->child[1]->name, "RELOP") == 0) {
        Operand a = operandForCond(e->child[0]);
        Operand b = operandForCond(e->child[2]);
        if (!operandIsSimple(a)) { Operand t = opVar(newTempName());
                                   tail = translateExp(tail, e->child[0], t, NULL); a = t; }
        if (!operandIsSimple(b)) { Operand t = opVar(newTempName());
                                   tail = translateExp(tail, e->child[2], t, NULL); b = t; }
        InterCode *c = newCode(IR_IF);
        c->u.iff.x = a; c->u.iff.y = b; c->u.iff.relop = irRelopCode(e->child[1]->lexeme);
        c->u.iff.z = opLabel(lt);
        tail = irAppend(tail, c);
        return appendGoto(tail, lf);
    }
    if (k == EX_UNARY && isTok(e->child[0], "NOT"))
        return translateCond(tail, e->child[1], lf, lt);        /* ★ 目标互换 */
    if (k == EX_BINOP && strcmp(e->child[1]->name, "AND") == 0) {
        char *l1 = newLabelName();
        tail = translateCond(tail, e->child[0], l1, lf);
        tail = appendLabel(tail, l1);
        return translateCond(tail, e->child[2], lt, lf);
    }
    if (k == EX_BINOP && strcmp(e->child[1]->name, "OR") == 0) {
        char *l1 = newLabelName();
        tail = translateCond(tail, e->child[0], lt, l1);
        tail = appendLabel(tail, l1);
        return translateCond(tail, e->child[2], lt, lf);
    }
    /* (other cases)：求值到 t1 再与 #0 比较 */
    {
        Operand t1 = opVar(newTempName());
        tail = translateExp(tail, e, t1, NULL);
        InterCode *c = newCode(IR_IF);
        c->u.iff.x = t1; c->u.iff.y = opConst(0);
        c->u.iff.relop = irRelopCode("!="); c->u.iff.z = opLabel(lt);
        tail = irAppend(tail, c);
        return appendGoto(tail, lf);
    }
}
```

`operandForCond(e)`：若 `classifyExp(e)` 是 `EX_INT` → `opConst(v)`；`EX_ID` → `opVar(varNameOf(...))`；
否则返回 `NULL`（表示"需要先求值到临时变量"，即 `!operandIsSimple(a)` 分支）。
**这一处就是 §6.1 表里"`if (n > 0)` 只用一条 IF 指令"的来源。**

关系运算符文本到代号：`irRelopCode` 接受 `< <= > >= == !=`；
AST 里 `RELOP` 结点的 `lexeme` 就是这六个之一（`syntax.y` 直接存原文）。

```c
        tail = translateStmt(tail, s->child[4]);
        tail = appendLabel(tail, l2);
        return tail;
    }

    case ST_IFELSE: {
        char *l1 = newLabelName(), *l2 = newLabelName(), *l3 = newLabelName();
        tail = translateCond(tail, s->child[2], l1, l2);
        tail = appendLabel(tail, l1);
        tail = translateStmt(tail, s->child[4]);
        tail = appendGoto(tail, l3);
        tail = appendLabel(tail, l2);
        tail = translateStmt(tail, s->child[6]);
        tail = appendLabel(tail, l3);
        return tail;
    }

        tail = translateCond(tail, s->child[2], l2, l3);
        tail = appendLabel(tail, l2);
        tail = translateStmt(tail, s->child[4]);
```

```c
/* ExtDef 的三种形态靠孩子结构区分（见 syntax.y）：
 *   [Specifier, ExtDecList, SEMI]      全局变量 —— 假设 4 保证不出现，跳过
 *   [Specifier, SEMI]                  结构体定义 —— 跳过
 *   [Specifier, FunDec, CompSt]        函数定义 —— ★ 本任务处理
 *   [Specifier, FunDec, SEMI]          函数声明 —— 假设 6 保证不出现，跳过
 *   [error, SEMI]                      错误恢复 —— 假设 7 保证不出现
 */
InterCodeList *translateExtDef(InterCodeList *tail, Node *e) {
    if (e->nchild != 3) return tail;
    if (e->child[1]->type != NT_FUNDEC) return tail;
    if (e->child[2]->type != NT_COMPST) return tail;

    Node *fd = e->child[1];                    /* FunDec : ID LP [VarList] RP */
    const char *fname = fd->child[0]->lexeme;

    { InterCode *c = newCode(IR_FUNCTION); c->u.one.x = opFunc(fname);
      tail = irAppend(tail, c); }

    /* 形参：按声明顺序发 PARAM（虚拟机的 ARG 压栈 / PARAM 弹栈决定了实参要逆序，见 Task 11） */
    if (fd->nchild == 4) tail = translateVarListAsParams(tail, fd->child[2]);

    tail = translateCompSt(tail, e->child[2]);
    return tail;
}

InterCodeList *translateProgram(Node *root) {
    InterCodeList *t = irList();
    Node *l = root->child[0];                  /* Program : ExtDefList */
    int i;
    translateResetNames();
    for (i = 0; i < l->nchild; i++) t = translateExtDef(t, l->child[i]);
    return t;
}
```

`translateVarListAsParams`：遍历 `VarList`（`[ParamDec COMMA VarList]` 或 `[ParamDec]`），
每个 `ParamDec : Specifier VarDec`，取 `VarDec` 的叶子名，发 `[PARAM vN]`。

- [ ] **Step 1: 实参逆序（★ 顺序写反是最容易犯且最难查的错）**

```c
/* Args : Exp | Exp COMMA Args
 * 头插得到逆序列表：translateArgs 递归到最右端先入列。
 * 依据：虚拟机 ARG 压栈、PARAM 弹栈（spec §3.4），故 ARG 顺序必须与 PARAM 相反。
 * 要求书 4.1.6 样例 2 的 fact(n-1) 只有一个实参看不出顺序；
 * 守护用例是 tests/func/argorder.cmm（三个形参、形参值各不相同）。 */
InterCodeList *translateArgs(InterCodeList *tail, Node *a, char **argList, int *n) {
    if (a->nchild == 1) {                        /* Args : Exp */
        Operand t = opVar(newTempName());
        tail = translateExp(tail, a->child[0], t, NULL);
        argList[(*n)++] = t->name;
        return tail;
    }
    /* Args : Exp COMMA Args —— 先把本项翻译出来暂存，递归完成后本项追加到末尾 */
    {
        Operand t = opVar(newTempName());
        tail = translateExp(tail, a->child[0], t, NULL);
        {
            char *mine = t->name;
            int   saveN = *n;
            /* 先把自身占位，再递归，最后把自身轮转到表尾 —— 见下方实现说明 */
        }
        tail = translateArgs(tail, a->child[2], argList, n);
        argList[(*n)++] = t->name;               /* 逆序：最右的实参最先被登记到尾部 */
        (void)0;
    }
    return tail;
}
```

> ⚠️ **别照抄上面的草稿** —— 它自相矛盾（既说头插又写成尾插）。正确的做法只有一种：
> **先复制 `argList` 里已递归得到的子串，再把本项放前面**。实现时请用：
> ```c
> if (a->nchild == 3) {
>     Operand t = opVar(newTempName());
>     tail = translateExp(tail, a->child[0], t, NULL);
>     char *sub[MAXARGS]; int subN = 0;
>     tail = translateArgs(tail, a->child[2], sub, &subN);
>     argList[0] = t->name;                        /* 本项在最前 */
>     for (i = 0; i < subN; i++) argList[1 + i] = sub[i];
>     *n = 1 + subN;
> }
> ```
> 这给出 `[本项, 右侧递归结果…]`，即**源码顺序的逆序**。

- [ ] **Step 1: 先把"链式"与"线性化"两种产物都写出来对照**

对 `int r[1][2]; r[0][i] = ...`：

**链式（不采用）**——把 `r[0]` 当成中间数组表达式，先物化行地址再重算：

```
t1 := &r
t2 := #0 * #8        （可折叠成 t2 := #0）
t3 := t1 + t2
t4 := i * #4
t5 := t3 + t4
*t5 := <值>
```

**线性化（采用）**——基地址 + 总偏移，行地址从不物化：

```
t1 := #0 * #8        （折叠后整条消失）
t2 := i * #4
t3 := t1 + t2        （t1 为 #0 时常量折叠消掉）
t4 := &r + t3
*t4 := <值>
```

**步骤 3 的常量折叠与代数化简（Task 17）会把上面两版都压到最短**；
但线性化能多消掉一条，这就是它值得做的理由。

- [ ] **Step 2: 实现多维下标**

```c
/* 对 Exp1[Exp2]：Exp1 的**类型**告诉我们还剩几维。
 * 用 types.h 的类型链求步长：step 进一层元素类型，步长 = 元素类型的字节数。 */
static int typeSizeBytes(Type t) {
    switch (t->kind) {
    case TY_BASIC:     return 4;
    case TY_ARRAY:     return t->u.array.size * typeSizeBytes(t->u.array.elem);
    case TY_STRUCTURE: /* 选做 3.1，不实现；走到这里应当已被 §1.2 的提示拦住 */
    default:           return 4;
    }
}
```

对表达式 `E0[E1][E2]…`：递归收集下标列表，然后

```
total = 0
cur = TypeOf(E0)
for k in 下标序列（从左到右）:
    cur = cur->u.array.elem
    total += k * typeSizeBytes(cur)
base = &E0（普通变量）或 E0（形参数组）
addr = base + total
```

> 实现上更省事且等价：**递归地把 `Exp1` 求成"基地址 + 已累计偏移"**，
> 每进一层只加一条 `MUL` 与一条 `ADD`，最后一次 `&`。

## ★ M4 前置：按**真实计数语义**重算每条优化的收益（2026-10-15，原版对拍后修正）

原版 irsim 对拍发现：真机主循环在 `execute_code` 之后**无条件 `ip += 1`**，而跳转分支把 `ip`
写成目标标号**自身**的下标 ⇒ **被跳转命中的 `LABEL`/`FUNCTION` 行会被跨过、既不执行也不计数；
落进去的标号行才计数**。（详见设计文档 §3.6 与 `docs/lab3/refsim-provenance.md`。）

**这条改写了若干优化的收益，动手前必须以本表为准**：

| 规则 | 真实动态收益 | 说明 |
|---|---|---|
| O1 常量折叠 / O2 代数化简 | **间接** | 单独看是 1 换 1（同样一条指令）。价值在于**使 O3/O4 能消掉那条临时变量** |
| O3 立即数内联 | **−1 / 每次执行** | 消掉 `t := #c` 这条赋值 |
| O4 结果直达 | **−1 / 每次执行** | 消掉紧接着的纯拷贝 |
| O5 冗余拷贝 | **−1 / 每次执行** | |
| O6 无引用标号删除 | **−1 / 每次落入** | 该标号没被引用 ⇒ 必是"落入"路径，删掉实打实省一条 |
| **O7 `GOTO` 紧跟其目标标号** | **0（净零！）** | 删掉 `GOTO` 后控制流改为**落入**那个标号 ⇒ **省 1 条 GOTO、多 1 条 LABEL**。⚠️ 旧模型（把跳转下一站算成标号本身）会误判为 −1，**整条规则是零收益**；保留它只作可读性/后续 pass 的铺垫，**报告里不得声称它省指令** |
| O8 `GOTO` 链折叠 | **−1 / 每次执行** | `GOTO L1`（L1 处又是 `GOTO L2`）两条变一条 |
| **O9 条件反转 + fall-through** | **−1 / 每次走假分支** | 真分支路径前后相同；省的是假分支上那条 `GOTO L2` |

**由此得到一条非平凡的结论，值得进报告亮点 3**：在**这个**计数模型下，
"删掉一条跳转"**未必**省指令 —— 因为跳转会让目标标号行被跨过，而落入会让它开始计数。
判据是**该指令在真实执行路径上是否被执行**，而不是它是否出现在文本里。
（这也解释了为什么 O7 与 O6 的收益一个为零、一个为正：差别只在"目标标号是否被引用"。）

**验证要求**：M4 的每一条规则都必须**用参考机测出优化前后的 `instr_cnt` 差值**并写进
`docs/lab3/instrcnt-log.md`（**实测，不推演**）；与上表预期不符的，**以实测为准并说明原因**。

## Task 17: 常量折叠与代数化简（O1、O2）

**Files:**
- Modify: `src/optimize.c`

**Interfaces:**
- Produces: `passConstFold`、`passAlgebra`

- [ ] **Step 1: 规则表（写进代码注释，逐条实现）**

**O1 常量折叠**：`ARITH` 两侧都是 `OP_CONST` ⇒ 换成 `ASSIGN x := #结果`。

| 输入 | 输出 |
|---|---|
| `x := #3 + #4` | `x := #7` |
| `x := #2 - #5` | `x := #-3` |
| `x := #6 * #7` | `x := #42` |
| `x := #7 / #2` | `x := #3` |
| `x := #-7 / #2` | `x := #-4` ← **必须与虚拟机的整除一致（P1）** |
| `x := #5 / #0` | **不折叠**（除零交运行期；折叠会让编译器自己崩） |

**O2 代数化简**：

| 输入 | 输出 |
|---|---|
| `x := y + #0` / `x := #0 + y` | `x := y` |
| `x := y - #0` | `x := y` |
| `x := y * #1` / `x := #1 * y` | `x := y` |
| `x := y / #1` | `x := y` |
| `x := y * #0` / `x := #0 * y` | `x := #0` |
| `x := #0 - y` | **不动**（这是取负，删不掉） |

> 全部规则作用于 `IR_ADD/SUB/MUL/DIV`；两侧操作数都是**已求值的变量或常数**（不是表达式），
> 所以完全没有副作用顾虑。

- [ ] **Step 2: 实现**

```c
static int foldArith(int kind, int a, int b, int *out) {
    switch (kind) {
    case IR_ADD: *out = a + b; return 1;
    case IR_SUB: *out = a - b; return 1;
    case IR_MUL: *out = a * b; return 1;
    case IR_DIV: if (b == 0) return 0;          /* ★ 除零不折叠 */
                 *out = floorDiv(a, b); return 1;   /* ★ 向下取整，与虚拟机一致 */
    }
    return 0;
}

/* 与 Python 的 // 同语义：向下取整。C 的 / 是向零截断，负数上不同（spec §3.7-1、P1）。 */
static int floorDiv(int a, int b) {
    int q = a / b, r = a % b;
```

## Task 18: 结果直达与立即数内联（O3、O4）

**Files:**
- Modify: `src/optimize.c`

**Interfaces:**
- Produces: `passCopyProp`、`passInlineConst`

**两条规则的精确定义：**

**O4 结果直达**：形如

```
MOV t, <rhs>        ← t 是临时变量，且全程序只被使用一次
MOV x, t            ← 紧接的下一条，且 t 出现在源操作数位置
```

⇒ 改写成 `MOV x, <rhs>` 并删除前一条。（`<rhs>` 可为任意合法源操作数。）

**O3 立即数内联**：形如 `MOV t, #c`（t 是临时变量）⇒
把所有**使用 t 的位置**替换成 `#c`，然后删除这条赋值。

> ⚠️ **O3 有一条硬性排除**：`t` **不得**出现在 `IR_ASSIGN_DEREF` / `IR_DEREF_ASSIGN` 的
> **地址操作数**位置（即 `place := *t` 里的 `t`）。原因：虚拟机的 `getValue('*...')`
> 会对 `var[1:]` 查 `symTable`，`*#5` 会 `KeyError` 崩掉 —— 生成出来的 IR 不再是合法文本。
> 实现时对"用作解引用基址的临时变量"打上不可内联的标记。

- [ ] **Step 1: 实现**

```c
/* 收集"不可内联"的临时变量：出现在解引用基址位置的那些 */
static void markDerefBases(InterCodeList *h, /* 位图或小数组 */ ...);

static int passInlineConst(InterCodeList *h) {
    int changed = 0;
    /* 第一遍：找出所有 MOV t, #c（t 是临时变量且未被标记） */
    /* 第二遍：把这些 t 的所有使用替换为对应的常数 */
    /* 第三遍：删除那些赋值（其左值此后无使用） */
    return changed;
}
```

## Task 19: 控制流精简（O6–O9）

**Files:**
- Modify: `src/optimize.c`

**规则定义（精确到可实现的模式匹配）：**

| # | 名称 | 模式 | 变换 |
|---|---|---|---|
| O6 | 无引用标号删除 | `LABEL L :` 且全程序无任何 `GOTO L` / `IF … GOTO L` / `CALL` 指向 L | 删除该行 |
| O7 | GOTO 紧邻 | `GOTO L` 的下一条**指令**是 `LABEL L :` | 删除该 `GOTO` |
| O8 | GOTO 链折叠 | `GOTO L1`，且 `LABEL L1 :` 的下一条指令是 `GOTO L2` | 改成 `GOTO L2` |
| O9 | 条件反转 + fall-through | `IF c GOTO L1` / `GOTO L2` / `LABEL L1 :` / BODY / `LABEL L2 :`，且 **L1 只被这一处引用** | 改为 `IF !c GOTO L2` / BODY / `LABEL L2 :`（删除 `GOTO L2` 与 `LABEL L1 :`） |

O9 的关系取反表：`>`↔`<=`、`<`↔`>=`、`==`↔`!=`。

> O9 是四者里唯一"真的少一条指令"的（其余三条省的是**静态**行数，只有 O9 减少**动态**执行条数）。
> 这是因为每次进入 `if` 都要执行那条 `GOTO L2`。**报告里要讲清这个区别**：
> 虚拟机的效率指标是**动态**条数，静态行数下降本身不等于效率提高。

- [ ] **Step 1: 实现**

`passGotoSimplify` 覆盖 O7/O8；`passCondInvert` 覆盖 O9；`passDeadLabel` 覆盖 O6
（必须**最后**跑，因为前面的 pass 会制造出无引用标号）。

标号引用计数：

```c
static int labelRefCount(InterCodeList *h, const char *name) {
    int n = 0; InterCodeList *p;
    for (p = h->next; p != h; p = p->next) {
        InterCode *c = p->code;
        if ((c->kind == IR_GOTO || c->kind == IR_LABEL || c->kind == IR_FUNCTION)
            && c->u.one.x->kind == OP_LABEL && strcmp(c->u.one.x->name, name) == 0) {
            if (c->kind != IR_GOTO) continue;        /* LABEL/FUNCTION 是定义，不算引用 */
            n++;
        }
        if (c->kind == IR_IF && c->u.iff.z->kind == OP_LABEL
            && strcmp(c->u.iff.z->name, name) == 0) n++;
        if (c->kind == IR_CALL && strcmp(c->u.call.f->name, name) == 0) n++;
    }
    return n;
}
```

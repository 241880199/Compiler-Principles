# 实验四（目标代码生成）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在实验三的 IR 之上增加 MIPS32 目标代码生成，使 `./cc in.cmm out.s` 产出的汇编能在 SPIM 上正确运行，并交付 3 页报告与 `proj4_submission.zip`。

**Architecture:** 新增独立的 `src/target.c`，只读 `InterCodeList`，按“函数预扫描 → 栈帧分配 → 逐条指令选择”输出汇编。所有变量驻栈（指导书的朴素寄存器分配），调用一律经栈传参，局部访问一律经 `$fp`，因此递归/嵌套调用不需要保存 `$t`/`$a` 寄存器。

**Tech Stack:** C99 / GCC；WSL Ubuntu 22.04 内的 flex 2.6.4 / bison 3.8.2 / make 4.3；SPIM 8.0（`spim -quiet -file`）。

**依据文档：** `docs/superpowers/specs/2026-11-05-cmm-lab4-design.md`（唯一需求来源）。

`src/target.c` 先只输出固定头与每个函数一个空标签：

```c
#include "target.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void internalError(const char *msg) {
    fprintf(stderr, "internal error (target): %s\n", msg);
    abort();
}

void generateMIPS(FILE *out, InterCodeList *ir) {
    InterCodeList *h = irHead(ir), *p;
    if (!h) return;
    fputs(".data\n.text\n.globl main\n", out);
    for (p = h->next; p != h; p = p->next) {
        if (p->code->kind == IR_FUNCTION) {
            fprintf(out, "%s:\n", p->code->u.one.x->name);
        }
    }
}
```

`src/main.c` 在 `translateProgram/optimizeIR` 之后分派：

```c
int emitMips = 1;
if (irFlag) emitMips = 0;
else if (asmFlag) emitMips = 1;
else if (outName && hasSuffix(outName, ".ir")) emitMips = 0;
if (emitMips) generateMIPS(out, ir); else printIR(out, ir);
```

- [ ] **Step 2: 实现预扫描**

```c
#define MAX_SLOTS 4096
typedef struct { const char *name; int offset; int size; } Slot;
typedef struct {
    const char *name;
    Slot slots[MAX_SLOTS]; int nslots;
    const char *params[MAX_SLOTS]; int nparams;
    int frameSize;
} FuncInfo;

static Slot *findSlot(FuncInfo *fi, const char *name);
static void addSlot(FuncInfo *fi, const char *name, int size); /* 已存在则取较大 size */
static void scanFunction(FuncInfo *fi, InterCodeList *h, InterCodeList *stop);
```

`scanFunction` 遍历 `[h->next, stop)`：
- `IR_DEC`：`addSlot(x->name, size)`
- `IR_PARAM`：记入 `params[]` 并 `addSlot(x->name, 4)`
- 其余：把每个 `OP_VAR` / `OP_ADDR` 的操作数名 `addSlot(name, 4)`（数组已由 DEC 登记，取较大值）

分配偏移（从 `$fp` 向下）：
```c
int cur = 8;                       /* 旧 $ra + 旧 $fp */
for each slot in 收集顺序:
    cur += slot.size;
    slot.offset = -cur;
frameSize = (cur + 7) & ~7;
```

- [ ] **Step 3: 实现 prologue/epilogue 与标量指令**

```c
static void emitPrologue(FILE *out, FuncInfo *fi) {
    fprintf(out, "%s:\n", fi->name);
    fprintf(out, "  addiu $sp, $sp, -%d\n", fi->frameSize);
    fprintf(out, "  sw $ra, %d($sp)\n", fi->frameSize - 4);
    fprintf(out, "  sw $fp, %d($sp)\n", fi->frameSize - 8);
    fprintf(out, "  addiu $fp, $sp, %d\n", fi->frameSize);
    for (i = 0; i < fi->nparams; i++) {
        fprintf(out, "  lw $t0, %d($fp)\n", 4 * i);
        fprintf(out, "  sw $t0, %d($fp)\n", findSlot(fi, fi->params[i])->offset);
    }
}

static void emitEpilogue(FILE *out, FuncInfo *fi) {
    fprintf(out, ".Lret_%s:\n", fi->name);
    fputs("  lw $ra, -4($fp)\n  move $sp, $fp\n  lw $fp, -8($sp)\n  jr $ra\n", out);
}
```

`loadOperand`：
```c
if (o->kind == OP_CONST) fprintf(out, "  li %s, %d\n", reg, o->value);
else if (o->kind == OP_VAR) fprintf(out, "  lw %s, %d($fp)\n", reg, findSlot(...)->offset);
else if (o->kind == OP_ADDR) fprintf(out, "  addiu %s, $fp, %d\n", reg, findSlot(...)->offset);
else internalError("loadOperand: bad operand");
```
`storeOperand` 只接受 `OP_VAR`，`sw reg, offset($fp)`。

逐指令：
- `ASSIGN`：`loadOperand(y,$t0); storeOperand(x,$t0)`
- `ADD/SUB`：分别 `lw` 到 `$t0/$t1`，`add/sub $t2,$t0,$t1`，`sw $t2`
- `MUL`：`mult $t0,$t1; mflo $t2`
- `DIV`：Task 3 的 floor 版本
- `LABEL`：`name:`
- `GOTO`：`j name`
- `IF`：`load x->$t0, y->$t1`，按 relop 发 `beq/bne/bgt/blt/bge/ble`
- `RETURN`：`load x->$v0; j .Lret_<f>`
- `READ`：`li $v0,5; syscall; sw $v0,slot(x)`
- `WRITE`：`load x->$a0; li $v0,1; syscall; li $v0,11; li $a0,10; syscall`

- [ ] **Step 2: 实现 ARG/CALL**

```c
/* ARG x：压栈 */
loadOperand(out, fi, x, "$t0");
fputs("  addiu $sp, $sp, -4\n  sw $t0, 0($sp)\n", out);
pendingArgs++;

/* CALL f：调用者清理 */
fprintf(out, "  jal %s\n", f->name);
if (pendingArgs) fprintf(out, "  addiu $sp, $sp, %d\n", 4 * pendingArgs);
pendingArgs = 0;
storeOperand(out, fi, x, "$v0");
```

- [ ] **Step 3: 实现 floor 除法**

```asm
  div $t0, $t1
  mflo $t2
  mfhi $t3
  beq $t3, $zero, .Ldiv_N
  xor $t3, $t0, $t1
  bgez $t3, .Ldiv_N
  addi $t2, $t2, -1
.Ldiv_N:
```
（`.Ldiv_N` 用全局递增计数器，保证唯一。）

## Task 5: 测试台与全量回归

**Files:**

- Create: `Test/lab4/**`
- Modify: `README.md`

- [ ] **Step 1: 写测试台**

```bash
#!/usr/bin/env bash
set -u
cd "$(dirname "$0")/.."
mkdir -p build/lab4
pass=0; fail=0
for d in Test/lab3/basic Test/lab3/arr1d Test/lab3/arrnd Test/lab3/func Test/lab3/req Test/lab4; do
  for cmm in "$d"/*.cmm; do
    [ -e "$cmm" ] || continue
    base=${cmm%.cmm}; in="$base.in"; exp="$base.exp"
    [ -f "$in" ] || in=/dev/null
    [ -f "$exp" ] || { echo "FAIL $cmm 缺 .exp"; fail=$((fail+1)); continue; }
    s="build/lab4/$(basename "$d")_$(basename "$base").s"
    if ! ./cc "$cmm" "$s" >/dev/null 2>build/lab4/cc.err; then
      echo "FAIL $cmm cc 失败"; fail=$((fail+1)); continue
    fi
    if spim -quiet -file "$s" < "$in" > build/lab4/out.txt 2> build/lab4/spim.err; then
      if diff -q "$exp" build/lab4/out.txt >/dev/null; then
        pass=$((pass+1))
      else
        echo "FAIL $cmm 输出不符"; diff -u "$exp" build/lab4/out.txt | head -10
        fail=$((fail+1))
      fi
    else
      echo "FAIL $cmm SPIM 非零退出"; head -5 build/lab4/spim.err; fail=$((fail+1))
    fi
  done
done
echo "lab4: 通过 $pass 个，失败 $fail 个"
[ "$pass" -gt 0 ] && [ "$fail" -eq 0 ]
```

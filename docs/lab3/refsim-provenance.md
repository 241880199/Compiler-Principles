# 参考机 `scripts/irsim_ref.py` 的出处与残余风险

本文记录无头参考机（`scripts/irsim_ref.py`）**每一条语义**的来源：它对应设计文档
`docs/superpowers/specs/2026-10-15-cmm-lab3-design.md` 的哪一节、有没有**独立于我们自己推演**的
证据背书。凡"被官方样例背书"者，指《实验三——中间代码生成.pdf》4.1.6 给出的两段**官方中间代码**
（`Test/lab3/unit_exec/sample2.ir` 与 `sample_opt1.ir`，逐字抄录并已机械核对 17/17、28/28 全等）
在真实执行时**只有**在该条语义正确的前提下才会得到官方语义（m! / sgn(n)）。

> 证据分级：
> - **【官方样例】** —— 由 4.1.6 两段官方 IR 背书（本实验里**唯一不来自我们自己推演**的一类证据）。
> - **【字节码】** —— 由对 `作业三/irsim.pyc` 的字节码反解背书（设计文档 §3 的来源）。
> - **【无独立证据】** —— 只有字节码/推演，没有任何官方样例能区分对错 ⇒ **残余风险**。

## 1. 逐条对照

| 参考机语义（设计文档小节） | 证据 | 说明 |
|---|---|---|
| 逐行读、空白行**整行跳过**、不占 `codes` 下标（§3.1） | **【官方样例】** | `sample2.ir` 第 13 行就是空行（两个函数之间）。若空行占一个下标，`FUNCTION main` 的 `entranceIP`、`labels` 与 `codes` 下标全部错位，`GOTO`/`CALL` 会跳错 ⇒ 跑不出 120。 |
| `FUNCTION main` 的入口 = 该行在 `codes` 里的**下标**（不是物理行号）（§3.2） | **【官方样例】** | 同上：`sample2.ir` 的空行正卡在 `main` 之前，是这条与"空行跳过"的联合判据。 |
| `LABEL x :` / `FUNCTION f :` 的形状与登记（§3.2） | **【官方样例】** | 两段样例都大量使用标号与 `GOTO`。 |
| `GOTO x` = `ip = labelTable[x]`（§3.2） | **【官方样例】** | `sample_opt1.ir` 靠 `GOTO label3`/`label1`/`label2` 走三条分支；跳错就得到错的 sgn。 |
| `IF x op y GOTO z` 的关系运算 `>`、`<`、`==`（§3.2） | **【官方样例】** | `sample2.ir` 用 `==`（基例）与 `>`（main 分叉）；`sample_opt1.ir` 用 `>` 与 `<`。 |
| `READ x` / `WRITE x` 的形状与语义（§3.2、§3.3） | **【官方样例】** | 两段样例的输入输出路径。 |
| `ARG x` 压栈 / `PARAM x` 弹栈，**实参书写顺序与形参声明顺序相反**（§3.4） | **【官方样例】** | `sample2.ir` 只有单形参 `fact`，顺序反/正都凑巧同值 ⇒ 这条由 `sample2.ir` 的**弱**背书；真正把顺序钉死的是要求书 4.1.1 第 10 条与 `rec.ir`/`argorder.ir`（自造）。 |
| `CALL f` 为被调函数**重新分配**局部变量地址、`RETURN` 时**恢复**（§3.4） | **【官方样例】★** | `sample2.ir` 的 `fact` 是**递归**：`t2 := CALL fact`（自己调自己）。若不重分配地址，内层 `v1` 会覆盖外层 ⇒ 得不到 120。这是本实验里对调用约定**最强**的一条外部证据。 |
| `RETURN x`：把返回值写进**调用点那个变量**（`x := CALL f` 的 `x`）（§3.4） | **【官方样例】★** | `sample2.ir` 里 `t2 := CALL fact` 之后接着 `t3 := v1 * t2`；返回值若不写回 `t2`，乘法就用错值 ⇒ 得不到 120。 |
| `RETURN x` 在调用栈空时 = 程序正常结束（§3.4） | **【官方样例】** | `sample2.ir` 的 `main` 以 `RETURN #0` 收尾，`status` 须为 `ok`。 |
| `RETURN x` 的 `x` 可以不是立即数（`RETURN v1`、`RETURN t2`、`RETURN t3`）（§3.3/§3.4） | **【官方样例】** | `sample2.ir` 基例 `RETURN v1`、递归 `RETURN t3`；`sample_opt1.ir` `RETURN t2`。 |
| `x := y`（`MOV`）双向语义（§3.3） | **【官方样例】** | 两段样例到处是 `v1 := t1`、`v2 := t4`、`v3 := t5`、`t3 := #1` 等。 |
| `#n` 立即数取值，**可带负号** `#-1`（§3.3） | **【官方样例】** | `sample_opt1.ir` 的 `t6 := #-1` —— 若解析不了负立即数，`sgn(-7)` 会得不到 -1。 |
| `x := a op b` 的 `-` 与 `*`（§3.2） | **【官方样例】** | `sample2.ir` 的 `t1 := v1 - #1`、`t3 := v1 * t2`。 |
| `x := CALL f` 的记录形式 `('CALL', x, f)`（§3.4） | **【官方样例】** | `sample2.ir` 的 `t2 := CALL fact`、`t5 := CALL fact`。 |
| `WRITE` 无 `isalpha` 限制（§3.2） | **【字节码】** | 官方样例只 `WRITE` 变量，未写 `WRITE #5`。 |

## 2. 没有任何独立证据的语义（残余风险）

下列各条**只有字节码/推演**支撑，4.1.6 的两段官方样例**根本走不到**，故它们的正确性
在本实验里**没有外部判据**。交付前若要加保险，应优先用**原版 irsim**（Python 3.8 + PyQt5）
抽验这几点：

1. **`DEC x size` 指令**（§3.2）—— 官方样例不含数组，从不出现 `DEC`。参考机把它实现为
   无操作但**计数 1**；计数是否真的 +1 只有字节码依据。
2. **解引用 `*var` / 取地址 `&var` 的全部形态**（§3.3）—— 官方样例无一用到指针写法。
   连带 §3.7-2 两条"陷阱"（`*x := a op b`、`*x := CALL f` 应抛 `KeyError`）也无官方背书，
   只有字节码 + 自造夹具（`deref_arith.ir`/`deref_call.ir`/`deref_mov.ir`）。
3. **`/` 的整除（向下取整）语义**（§3.7-1）—— 官方样例无除法。`-7/2` 得 `-4` 只有字节码依据。
4. **「被引用的标号必须有定义」这条检查**（§3）—— 设计文档已声明：真机确有 `labelCheck`，
   但其实现**未被反解确证**；参考机里保留的是一层**我们自己的防御性检查**，对我们生成的 IR 无实害。
5. **内存模型细节**（§3.5）—— `mem = [0]*262144`、按**字节**计址 `//4`、`offset > 1 MiB` 判失败、
   运行期越界 → `IndexError` → `status=="memory"`、`PARAM` 遇空 `argumentStack` 也被报成内存错。
   官方样例既不越界也不碰数组边界，全部只有字节码依据（自造夹具覆盖）。
6. **`instrCnt` 的计数口径与绝对值**（§3.6）—— "_`execute_code` 第一件事就 +1，故 `LABEL`/`FUNCTION`/
   `DEC` 都计数_"这条**规则**来自字节码；官方样例**没有给出任何期望指令数**，故绝对计数无外部判据。
   本任务只做到：官方两版的动态路径可被 `run(trace=True)` 逐条复算、且**优化版确实少于原始版**
   （sign.ir 18 条 vs sample_opt1.ir 11 条，n=-7），这与要求书"优化减少执行指令数"的定性主张一致。
7. **`status == "pc"`（IP 越过 `codes` 末尾）**（§3.7-5）—— 官方两段样例都有正常 `RETURN` 出口，
   走不到这一档；只有字节码依据。
8. **关系运算 `>=`、`<=`、`!=`**（§3.2）—— 官方样例只用到 `>`、`<`、`==`。
9. **`GOTO`/`IF`/`CALL` 之外形态的装载期校验**（§3.2）—— 例如 `&`/`#` 不能作 `:=` 左值、
   `RELOPS` 白名单、`DEC` 的 `%4` 校验等，官方样例都是合法输入，无反面判据（自造 `unit_parse` 覆盖）。

## 3. 结论

- 参考机的**执行内核主体**（分词/装载、`FUNCTION`/`LABEL`/`GOTO`、`IF` 的关系运算、
  `MOV`、`READ`/`WRITE`、`ARG`/`PARAM`、`CALL` 的地址重分配与恢复、`RETURN` 写回调用点变量）
  被 4.1.6 两段**官方样例**独立背书 —— 这是本实验里除自造夹具外**唯一的外部证据源**。
- 上述第 2 节的九类语义**没有官方样例背书**；它们是"本地绿、线上可能不一致"的**残余风险清单**。
  其中**计数口径**与**除法语义**直接关系到优化正确性与期望输出 oracle，风险优先级最高。
